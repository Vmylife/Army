國軍模擬器 Army v0.10.9｜3D 軍營道路尋路／碰撞修正

【安裝基礎】
請先確認目前已安裝 v0.10.8（30人自主 NPC 版本）。
本 ZIP 只包含有變動及新增的檔案；不含模型與整包遊戲。
全部按 ZIP 內相對路徑上傳到 GitHub Vmylife/Army 倉庫根目錄。
覆蓋 index.html，新增加的 bootstrap109.js、main109.js、layout109.js、navCollision109.js、npcLife109.js、navDebug109.js 請保留目錄結構。
舊檔（v0.10.8）可留著，不需刪除。

【更新項目】
1. 建築碰撞改為依建築面向計算旋轉矩形；重新收緊碰撞占地，減少外牆前的空氣牆。
2. 玩家／NPC／導航格使用同一套建築與道具碰撞測試，降低規劃說能走、現場卻不能走的情形。
3. 原有道路中心線位置不變，部分主要路和連接支路略微加寬，避免修改你已完成的建築佈局。
4. NPC 遠距離路線優先走道路；到目的地附近，才走入操場、座位、訓練區等場地。
5. 30 名 NPC 加上腳下圓形身體碰撞及局部避讓；玩家前進時 NPC 優先讓路，避免大量穿模。
6. NPC 卡住時在 1.2 秒左右開始重新找路；無路可走時有間隔重試，無法完成的活動會放棄重選。
7. 結伴散步會依路點持續移動，有機會一起停下聊天，並非到達第一個目的地後停在原地。
8. 刪除「整理裝備」活動（其他活動保留）。
9. 網址加 ?debug 可顯示 FPS、NPC 人數與碰撞線；右上角可切換「碰撞線：開／關」。藍色為道路、橙色為建築碰撞、紅色為道具碰撞、黃色為 NPC 身體間距、綠色為當前導航路徑。

【已測試】
JavaScript 語法、模組引用靜態檢查，以及根據現有軍營配置建立的 30 名 NPC 六分鐘行為／碰撞模擬（三輪）；模擬未發現 NPC 走入建築碰撞範圍。
這是資料／邏輯模擬，不等於已在你的 iPhone 實機跑完完整 3D 場景。

【可能仍需校正】
目前建築碰撞以經驗係數估算地面占地（不是逐頂點物理碰撞），不同外型或屋簷可能需要個別微調；NPC 在非常窄的通道或密集排隊時，仍可能短暫等待、重新繞路。
道路偏好為「優先」，不是完全禁止走草地；草地內有些活動必須離開道路才能執行。
