Army v0.13.3 — 2.5D 角色美術實裝更新檔

覆蓋方式：
把 ZIP 解壓後，保持資料夾結構，上傳至 GitHub Vmylife/Army 儲存庫最外層。
直接打開 https://vmylife.github.io/Army/battle2p5d.html?version=0133
請確認 HTML、JS、CSS、assets/*.png 全都成功上傳。

更新：
- 綠軍低持槍跑步圖、綠軍舉槍圖、紅軍舉槍圖共 3 張，去除白底並裁切成透明 PNG。
- 主角自動鎖定射程內敵人時，切換舉槍圖；脫離射程回復低持槍圖。
- 雙方會根據目標方向左右鏡像：不必另外製作朝左素材。
- 槍口火光是程式效果，沒有畫死在人物圖片上。
- 開場 17 位紅軍，後續持續增援；上限依視窗寬度調整，避免無限制增加。
- 更正等角投影下搖桿與 WASD 的方向，上即螢幕上、右即螢幕右。
- 延續 v0.13.2「隱藏載入視窗」修復，並讓三張 PNG 載入完成才進入戰鬥。
- 不修改 3D 軍營與文字戰場人生系統。

注意：
- 綠軍目前只有兩張靜態姿勢，切換時沒有額外的過渡影格；移動的上下擺動是簡單視覺模擬。
- 本版仍是測試原型，敵人 AI、戰場地圖與技能尚未定稿。
