Army v0.13.4 — 2.5D 戰鬥特效更新檔

【安裝】
基礎：已部署 v0.13.3（三張角色圖）的 Army 儲存庫。
解壓後把所有檔案依照資料夾結構上傳 GitHub 覆蓋。

需要覆蓋：
  battle2p5d.html
  src/battle2p5d/game.js

需要新增：
  src/battle2p5d/assets/hero_muzzle_01.png ~ 04.png
  src/battle2p5d/assets/hit_soldier_01.png ~ 03.png
  src/battle2p5d/assets/hit_cover_01.png ~ 03.png

不需要重新上傳主角和敵人的三張 PNG，也不需要改 3D 軍營。

【變更】
1. 玩家子彈使用即時更新的世界座標，不用「長條子彈 PNG」代替飛行。
2. 黃白彈頭 + 金黃尾光；連續軌跡保留短時間，並繪於人物前景。
3. 玩家開火時，隨機顯示四款透明 PNG 槍口火光；敵人維持較小的程式火光。
4. 新增人物命中 / 木箱沙包命中各 3 格貼圖動畫（0.138 秒）。
5. 子彈從人物圖片的槍口位置發射；身體命中點不再取腳底。
6. 使用掃掠碰撞線段判定飛行路徑，降低高速子彈穿過目標的問題。
7. 彈道拖尾、命中特效數量設上限以控制手機負載。

【驗收】
可開啟 /battle2p5d.html?version=0134；切換普通 / 超強士兵，觀察
飛行子彈、左右鏡像槍口火光、命中掩體與敵軍的火花。

【範圍】
僅 2.5D 戰鬥，不影響其他玩法；本版未增加正式養成系統。
