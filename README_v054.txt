# Army v0.5.4 — 角色看不到／操控無反應診斷修正

先確認已在 GitHub Pages 開啟 `army-playtest.html?v=054`。

## 需要覆蓋的檔案
- `army-playtest.html`
- `src/main.js`
- `src/core/renderer.js`
- `src/ui/input.js`

此更新不改動模型、地圖、動畫資料、移動速度、小地圖或主要遊戲入口。

## 修正
- 在角色繪製時一次性檢查 WebGL 錯誤及畫面像素差。
- 若 GPU 骨架著色器沒有畫出角色，自動切換成保留貼圖的**靜態模型**備援，確保人物至少可見且可移動。備援狀態下手腳動畫暫時不動，這是診斷機制。
- 若兩種角色繪製方式都失敗，直接在畫面顯示 WebGL 診斷文字，不再只顯示空白地圖。
- 動畫更新迴圈加入例外資訊回報，避免發生錯誤時靜默停止。
- 角色操控處理 Safari 無法取得 pointer capture 的情況。

**注意**：開發環境的 Chromium 無法建立 WebGL2 上下文，本次可做程式結構及骨架數據測試，無法宣稱 Safari 實機通過。請實機驗證。若看到錯誤文字，截圖即可確認問題而不需要再猜。
