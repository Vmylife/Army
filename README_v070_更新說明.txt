Army v0.7｜新兵訓練營 22.0 地圖重製（只包含更動檔案）
================================================

基底：已可遊玩的 Army v0.6.2，GitHub 儲存庫 Vmylife/Army。
這不是完整遊戲包。請勿刪除原本 assets/、src/ 等其他檔案。

修改內容
--------
1. 依你提供的 22.0 配置圖，重排 3D 營區：
   西側：營舍、大操場、手榴彈投擲場、中山室、吸菸區
   北側：後山、靶場、彈藥庫、500 公尺障礙場
   中／東側：單兵戰鬥教練場、毒氣室、營站、餐廳、洗手洗碗區
   南側：連隊集合場、體能場、軍械室、醫務所、會客室、大門
2. 11 棟特色建築（立面、屋簷、陽台／鞋櫃、販賣機、洗碗水槽、
   醫務所紅十字、軍械室鐵門、靶場標靶、單戰場沙包與障礙等）。
3. 左上小地圖與可點開的大地圖，完全使用與 3D 一樣的地圖資料。
   固定北方朝上，玩家藍色箭頭跟著轉向。
4. 保留 v0.6.2 的雙指縮放、隱藏搖桿、走／跑／衝刺、人物骨架動畫。
5. 出生在大門北側，紅隊在連隊集合場，19 個入口／訓練位置可步行抵達。

安裝
----
1. ZIP 解壓縮。
2. 將其中的 index.html 和 src/ 各檔案，依原本路徑覆蓋到 GitHub 的 Army 倉庫根目錄。
3. 所有原本的 GLB 模型與其他未列出的檔案維持原狀，不要刪除。
4. GitHub Pages 部署後，開啟 https://vmylife.github.io/Army/?v=070
   若看到舊版，請在 Safari 重新整理，或關閉舊分頁後重開。

測試記錄
--------
已檢查：所有 JS 語法、3D 場景幾何（約 9,503 三角形）、
無 NaN 座標、19 個地點可達性、紅隊與玩家出生點碰撞、
手機尺寸大地圖實際繪圖及開關。
未驗證：iPhone Safari WebGL2 實機 3D 渲染。
建議上傳後先確認角色是否出現、搖桿是否能走、雙指縮放正常。

注意：此版重點是地圖與低多邊形場景重製，不包含新的訓練小遊戲、
建築物內部或 Meshy 高精度模型。
