Army v0.7.1 — 地圖方向、道路地面、簡單建築修正
==============================================
以已部署的 Army v0.7 為基礎，不含模型，只需要覆蓋修改檔。

修正內容：
1. 小地圖：維持北方朝上，但不再永遠把玩家圖示鎖在正中央。角色在小地圖內移動，接近邊緣才平移地圖，直觀顯示左右方向。
2. 道路：將所有線狀道路預先合併成連通的單一網格；路口不再用重疊的圓形接頭，修正深度互搶的灰黑斑塊及路面接縫。2D / 3D 使用相同道路資料。
3. 地面：修正圓形訓練場面朝下造成的陰影；投擲區與操場改用不同高度，避免重疊閃爍。統一道路與訓練場的地面層次。
4. 建築：取消 v0.7 的陽台、棚架、雜亂外部裝飾，恢復最簡單的素色牆、雙斜屋頂、門窗造型。
5. 不修改主角與敵人 GLB、角色動畫、搖桿、視角縮放、大地圖開關、速度或碰撞資料。

請先把 GitHub 原版資料備份，再將本 ZIP 的下列檔案，照路徑覆蓋 Vmylife/Army：
- index.html
- src/main.js
- src/core/renderer.js
- src/map/campGeometry.js
- src/map/mapDrawing.js
- src/map/roadMesh.js (新增檔案，務必上傳)
- src/ui/minimap.js
- src/ui/worldMap.js

不必上傳或更改 assets/ 的模型檔。
請勿只上傳 ZIP；GitHub 網頁不會自行解壓 ZIP。
完成部署後測試：https://vmylife.github.io/Army/?v=071

已做 JS 語法、相依路徑、地面幾何有效數值、道路單一連通面、地圖指標左右移動測試。
瀏覽器環境限制了本機的 WebGL 網頁請求，尚未完成 iPhone Safari 的實際畫面驗證。
