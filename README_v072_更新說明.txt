Army v0.7.2｜小地圖方向與地面重疊修正

這是「只包含修改檔案」的更新包，必須覆蓋到已安裝 v0.7.1 的 Army 倉庫。

修正：
1. 左上小地圖的人物永遠位於正中央，地圖保持北方朝上。
2. 小地圖與大地圖藍色箭頭用「畫面上的操作方向」表示：向上滑＝朝上、向右滑＝朝右、向左滑＝朝左。放開後維持上一次面向。
   注意：若旋轉 3D 鏡頭，這個 UI 箭頭代表螢幕相對方向，而非真實北方羅盤方位。地圖本身不旋轉。
3. 500 公尺障礙場和單戰場先前在 Z=7.25～8.1 重疊 0.85 遊戲單位且同高度，修掉重疊；兩區地面現在不再有重合的水平面。

操作：
把本 ZIP 解壓縮，將 index.html 與 src/ 依原路徑覆蓋 GitHub 上的同名檔案。
不需重傳 assets 裡任何 GLB。不要刪掉現有 src/map/roadMesh.js，它沿用 0.7.1 的版本。
更新後可開 https://vmylife.github.io/Army/?v=072 。

未改動：主角模型、骨架、動畫、搖桿、碰撞、相機縮放、原本的連續路網、簡單建築。
