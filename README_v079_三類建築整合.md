# Army v0.7.9｜三類建築整合

更新基礎：Army v0.7.8（保留 v0.7.7 新士兵／紅隊、v0.7.6 固定大地圖及小地圖，並保留 v0.7.8 人物細線修正）。

## 新增三種 Meshy 模型，共九處

- 1 號 `assets/buildings/building-1-barracks.glb`：營舍、軍械室。
- 2 號 `assets/buildings/building-2-community.glb`：中山室、餐廳。
- 3 號 `assets/buildings/building-3-small-rear-fixed.glb`：彈藥庫、營站、醫務所、會客室、毒氣室。

3 號小建築已將沒有窗戶的背面中央多餘門口幾何移除，補上平整牆面及綠色底座，正面窗戶與正門保留。這是經過實際修改的 GLB，而非純畫面遮蓋。

## 實作說明

- 三種 GLB 各下載一次並建立共用 GPU 資源，九個地點使用不同縮放、旋轉及溫和的辨識色調，沒有產生九份獨立 GLB。
- 九棟原本的程式簡易建築不再重複渲染；地圖上的原座標、名稱和碰撞盒保持不變。
- 正門方向對準原建築配置中的 entry 入口座標；依原建築長寬與高度適配視覺尺寸。
- 保留原有洗碗區／警衛哨等非本次九種模型的簡易設施。
- 三棟模型首次載入會下載貼圖；若下載失敗，遊戲仍可進入，瀏覽器 Console 會顯示錯誤。
- 未改動主角／紅隊 GLB、人物動畫、地圖方位與搖桿。

## 重要：更新方式

從 v0.7.8 更新：解壓 `Army_v0.7.9_三建築更新檔.zip`，把裡面所有檔案和資料夾依原路徑上傳至 `Vmylife/Army` 的根目錄，覆蓋同名檔案，**不要多包一層資料夾**。

如果想要重建儲存庫，改使用 `Army_v0.7.9_完整遊戲.zip`；不需要兩份都上傳。GitHub Pages 的首頁是根目錄 `index.html`，網址仍為 `https://vmylife.github.io/Army/`。

## 驗證範圍

靜態檢查：程式語法、模型內嵌貼圖與三角面索引、九棟位置對應、ZIP 完整性。由於此環境無法完成可用的手機 WebGL 實機測試，部署後請優先檢查九棟外觀、入口方向、後牆和觸碰牆壁行為；如果個別建築有尺寸觀感差異，可只調整 `src/buildings/buildingRenderer.js` 的配置參數。
