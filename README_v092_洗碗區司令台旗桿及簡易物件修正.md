# Army v0.9.2｜洗碗區朝向、司令台及旗桿修正

本更新必須覆蓋 v0.9.1。

1. 洗碗區**中心位置不變** (43.2, 3.0)，鎖定模型正面朝營區內（世界 -X，yaw=-90 度）。不拉伸模型；互動入口調到其朝內的一側 (40.8, 3.0)。
2. 司令台移到旗桿右邊 (x=-17.6, z=-18.0)，不改原本方向，體積保留上一版。
3. 旗桿位置不變 (x=-23.0, z=-19.0)，等比縮小到 5.85 倍（由 8.25 倍調降約 29%），高度仍高於一般建築。
4. 從 3D 地圖移除 5 個教官站位方塊、3 個集合場鐵柱及 1 個手榴彈場木條，不動原有真實模型。
5. 更新大小地圖的司令台圖示位置，以及所有相關 JavaScript 引用快取版本。

**注意**：版本只包含更改的程式，不包含任何 GLB；沿用 v0.9.1 模型即可。
