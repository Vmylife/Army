國軍模擬器 Army — v0.9.4 地面美化更新
基準：Vmylife/Army main（2026-10-25 20:03 台灣時間的 v0.9.3 辦公大樓版）

更新內容：
  1. 草地加入低飽和、平滑的深淺起伏（無須外部材質）。
  2. 大操場與訓練場泥土地面加入細緻色差。
  3. 水泥道路加入淡淡的色差與細微接縫。
  4. 沿用既有地圖範圍、道路形狀、建築座標、GLB 素材和玩法設定。
  5. 繼續使用單一靜態網格繪製；無新增貼圖下載、無額外 draw call。

覆蓋路徑（本包僅有以下遊戲檔案）：
  index.html
  src/map/ground94.js  ← 新增

用法：解壓縮後，將上述路徑完整覆蓋／加入 GitHub Vmylife/Army 儲存庫根目錄。
本次不需要上傳任何既有大型 GLB。
若畫面仍舊，使用 Ctrl+F5 強制重整或手機重新開啟頁面。

技術備註：index.html 透過瀏覽器原生 import map，把舊渲染器的
campGeometry.js?v=092 模組載入轉給 ground94.js?v=094；
ground94.js 內部呼叫原本 campGeometry.js?v=093，保留全部舊幾何再疊加地面細節。
此方式可將更新限制在兩個檔案內。
