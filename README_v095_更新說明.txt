國軍模擬器 Army v0.9.5 — 單戰場／長椅／籃球場（僅更新檔）

以 GitHub Vmylife/Army 的 v0.9.3 及前次 v0.9.4 地面美化為基礎。
直接將 ZIP 內所有檔案依原資料夾位置覆蓋上傳 GitHub 即可。

本次更新：
1. 移除在圍欄旁、道路上不合理的舊長椅位置，重新放到中山室側邊、
   體能場旁、建築休息點，以及新籃球場外側。
2. 單兵戰鬥教練場：原本散落的沙包、桶子與箱子改成約五組混合掩體。
   500公尺障礙跑道及射擊場維持原樣，維持人員走動空間。
3. 中山室後方／大地圖右上角的圍欄向外拓展，留出新空地，
   加入簡易籃球場地板、雙籃框與標線，3D 地面、迷你地圖及大地圖同步擴增。
4. 延續前次 v0.9.4 的細微草地色差、道路接縫等美化。
