Army v0.7.4 — 小地圖方向一致修正（僅 4 個修改檔案）

請將 ZIP 裡的 index.html、src/main.js、src/ui/minimap.js、src/map/mapDrawing.js
按照原路徑覆蓋到 Vmylife/Army 根目錄。其他檔案、GLB 模型不須改動。

更動說明：
1. 人物藍點永遠固定在小地圖中央。
2. 修正「人物在螢幕上往右走，右側目標卻越來越遠」：小地圖不再以固定北方投影與螢幕相對搖桿混用，改為「鏡頭朝向」的小地圖投影。
   - 右移：底圖往左；左移：底圖往右。
   - 上移：底圖往下；下移：底圖往上。
   - 鏡頭轉動時，小地圖也跟著鏡頭轉，但不隨角色自身轉身旋轉。
3. 藍色箭頭維持螢幕操作方向，開啟大地圖則維持北方朝上，箭頭改為反映角色真實的世界面向。
4. 未更動 3D 場景、地面、道路、士兵模型、動畫或碰撞。

測試網頁：https://vmylife.github.io/Army/?v=074
