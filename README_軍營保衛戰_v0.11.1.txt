Army v0.11.1 — 軍營保衛戰（戰鬥重製測試版）

【安裝】
前提：Army 正式軍營已更新至 v0.10.5，原本地圖、模型、圖片資產都正常。
將 ZIP 內 battle.html 上傳至 GitHub 專案根目錄，將 src/battle/ 內的 5 個檔案依原資料夾放進 src/battle/。
ZIP 只包含這次需要新增或覆蓋的檔案。不要更動 index.html、src/main105.js 或其他既有軍營檔案。
舊版 src/combat/ 可留著，不會被新版 battle.html 載入。

【測試網址】
https://vmylife.github.io/Army/battle.html
更新後如仍載入舊版，測試 https://vmylife.github.io/Army/battle.html?version=0111

【主要功能】
・原封不動沿用軍營 v0.10.5 的地圖、地面、建築、道具、天空與柔和光照。
・沿用 ArmyRenderer、RigAnimator、setupInput、options：同一鏡頭設定、同一搖桿感應與鏡頭拖動、相同縮放上下限。
・戰鬥模式限定：移除西側（營舍側）與南側（哨口側）的周界圍欄。其他圍欄保留；正式軍營的圍欄不受影響。
・西側／南側戰鬥地圖邊界開放一小段草地，敵軍從圍欄外進場，不受原本的周界碰撞阻擋。
・主角由玩家自己操控移動，進入射程後自動搜尋可射擊的敵人；手持原有步槍。紅軍由兩個方向逐步湧入、移動與還擊。
・3D 子彈軌跡、槍口火光、命中扣血、死亡、戰鬥資訊與三分鐘結算。
・普通士兵：移動與射速較慢、射程短。超級士兵：移動／火力／射程／生命值皆強。
・沿用軍營場景的建築和道具碰撞；木箱、沙包與司令台會遮擋射線。
・不需要重新上傳任何大型 GLB 或 JPG。

【操作】
首頁選普通士兵／超級士兵，再按開始戰鬥。
手機：與軍營完全相同，畫面下半部觸控搖桿移動、上半部拖動鏡頭、雙指縮放。
電腦：WASD 或方向鍵移動、Shift 加速、滑鼠拖鏡頭與滾輪縮放。
靠近敵人後自動開火，玩家不需另按射擊鍵。
點左上小地圖可開軍營地圖。

【限制與驗收】
此版專注保留正式軍營畫面、手感，以及親自操控對抗人海。暫未加入手榴彈、軍營訓練能力、Boss、精細的敵軍協同 AI。
戰鬥演算法與介面已通過程式語法檢查、射線遮擋單元測試、模擬環境啟動與遊戲迴圈測試。
完整 GitHub Pages + 真實 GLB 的手機效能仍需部署後實機確認。部分敵軍在複雜建築角落可能繞路不佳，下一輪再優化。
