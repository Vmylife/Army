Army v0.10.0 — 軍營 3D 場景編輯器（獨立頁面）
===================================================

【安裝】
只需把 ZIP 內的「editor.html」及「src/editor/」上傳至 GitHub 儲存庫相同路徑。
不用覆蓋現有 index.html、src/main.js、地圖程式或任何 GLB。
本版本以既有 Army v0.9.9 的軍營資源為基礎。

【開啟】
部署完成後，開啟：
https://vmylife.github.io/Army/editor.html
（如果 GitHub Pages 設定了不同網域，以該網域的 /editor.html 為準。）

【使用】
- 左鍵點擊建築、路燈、籃框、木箱等場景物件，直接拖曳到新位置。
- 點擊空白地面並拖曳：平移鏡頭；按右鍵拖曳：繞營區旋轉鏡頭。
- 滾輪 / 右側以外的 ＋－ 按鈕：遠近縮放。
- 面板可直接修改 X、Z、角度（度數）、大小倍率。
- 物件很多難點到時，可用「物件清單」搜尋，例如：路燈、營舍、手榴彈箱。
- 旋轉視角開關可用在觸控裝置（觸控測試程度有限）。
- 復原 / 重做、重設單一物件、全部還原。
- 自動暫存於目前瀏覽器的 localStorage，但請定期匯出 JSON 避免清除瀏覽器資料後遺失。
- 「匯出配置 JSON」會下載一個可交回給 GPT 整合的資料檔。
- 「匯入 JSON」可恢復先前匯出的設定。

【目前限制】
- 只調整既有 3D 建築與道具模型的平移、旋轉、比例；不編輯地面材質、道路形狀、地圖圍欄邊界本身。
- 围欄是多段 GLB：可選取個別圍欄段移動，但不會自動重算整條邊界。
- 地面靜態陰影仍會維持舊位置（地面幾何是進入場景時產生）；正式整合時再同步。
- 編輯器不載入士兵操作或遊戲小遊戲；正式版仍由 index.html 執行。
- 改建築後，當前編輯畫面的道路、建築互動判定及碰撞不一定與模型完全一致，待整合時由 GPT 修正。
- 匯出的配置是布局資料，不會把任何更動直接寫入 GitHub 程式碼。

這包只有 3 個新檔案 + 本說明，不會修改遊戲現有主程式。
