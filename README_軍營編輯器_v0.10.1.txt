《國軍模擬器》獨立場景編輯器 v0.10.1

本次只更新編輯器（不修改正式遊戲）：
- editor.html
- src/editor/editor.js
- src/editor/editor.css

請把壓縮檔內的檔案，依照資料夾路徑覆蓋到 GitHub 儲存庫 Vmylife/Army。
入口：https://vmylife.github.io/Army/editor.html

新增功能：
1. 「新增物件」：選擇「建築」或「道具／裝飾」，再選模型種類，新增在鏡頭中心。
2. 「複製選取」：複製已選物件，位置錯開 1.7 單位。快捷鍵 Ctrl+D / Cmd+D。
3. 「刪除選取」：移除建築或裝飾物件；Delete / Backspace 可刪除，復原能找回。
4. 保留原本的拖曳、旋轉、調整比例、鏡頭、復原／重做。
5. 保存新增、刪除和移動的內容，匯出/匯入 JSON（schemaVersion 2）。
6. 嘗試沿用 v0.10.0 本機自動暫存及舊版 schemaVersion 1 匯出 JSON。

使用方式：
- 選擇素材種類，按「＋ 新增到鏡頭中心」，新增後用滑鼠拖曳到想要的地方。
- 選取場上的物件，按「複製選取」或「刪除選取」。
- 預設保存於同一個瀏覽器的 localStorage。不同裝置或清除網站資料後不會同步。
- 請定期使用「匯出配置 JSON」作為備份。匯出包含所有現存物件和刪除原有物件清單。
- 完成後把 JSON 交給 ChatGPT，再正式寫入軍營場景程式。

目前限制：
- 僅能新增專案「已具備的」3D 建築/道具種類，不能直接上傳新的 GLB。
- 編輯時不重新計算原版的靜態地面陰影，碰撞、建築互動位置、道路地形和小地圖仍需正式整合。
- 新增的建築暫時共用原建築模型 ID，匯出用獨立 editor key 區分；正式整合會重新設定 ID/互動點。
- 瀏覽器實測過模擬編輯場景的新增、刪除、復原、重做、匯入及匯出；未在 GitHub Pages 的完整模型環境實機測試。
