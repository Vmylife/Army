# Army v0.4 主角與敵軍軍營實玩測試

## 這次新增，不會覆蓋原有 `index.html`

- `army-playtest.html`：新 3D 軍營實玩入口
- `src/main.js`：玩家、敵軍與場景統合
- `src/core/`：GLB 解析、WebGL2 渲染與矩陣
- `src/characters/`：Mixamo 44 骨骼動畫控制（保留 Meshy 原始骨架）
- `src/map/`：營舍、道路、靶場、餐廳等場景配置
- `src/battle/`：測試敵人受擊、倒地與重置
- `src/ui/`：搖桿、手機介面與動畫選單
- `src/systems/`：共用參數
- `src/minigames/`：獨立小遊戲的預留模組位置
- `assets/characters/player/`：玩家高品質、原始完整 9 動畫 GLB
- `assets/characters/enemy/`：原版骨架與動畫保留的紅帽紅制服低模 GLB

## 部署

將解壓後的 **`army-playtest.html`、`src/`、`assets/`** 三項放到 `Vmylife/Army` 的**根目錄**。保留子資料夾結構；不要把全部檔案攤平；不要把 ZIP 當成唯一一個檔案上傳。

部署連結：`https://vmylife.github.io/Army/army-playtest.html`

## 操作

- 手機：左下虛擬搖桿移動、畫面空白處拖曳旋轉視角
- 電腦：WASD / 方向鍵移動，滑鼠拖曳旋轉鏡頭
- 下方按鈕：一般走路、跑步、慢走、衝刺、受擊、倒地、起身、拳擊。其他現有 Meshy 動畫可繼續擴增
- 走到紅隊敵人附近點「測試攻擊」三次，敵人倒地；「重置敵人」復原
- 「鏡頭復位」回到預設斜俯視角；「省電模型」降低渲染畫面負擔

## 限制

這個版本是軍營自由移動與戰鬥動畫**整合測試**，並非完整的訓練、技能、戰場或排行榜系統；舊版首頁不會被覆蓋。

主角使用 135,592 三角面高品質 Meshy 模型，敵人使用先前製作的約 16,271 三角面低模素材。手機 FPS 尚需實機實測。Meshy 原本只有 9 種動作，**沒有專門的敬禮、拿槍與射擊動畫**，這版沒有假裝已經有這些動作。現階段的拳擊、被擊飛、倒地都是匯出資料內的原始動畫。

紅隊模型從原圖貼圖選擇性換紅色，保留皮膚、頭髮、靴子原色。若正式遊戲需要多種兵種和裝備，可以沿用此貼圖處理方式，無需重新付費生成角色。
